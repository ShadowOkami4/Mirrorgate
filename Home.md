## How to use this vault

1. **Everything here is written for the Game Master.** Each page tells the whole truth. What players may know sits in a **Player info** box at the bottom of the page, ready to read aloud or share.
2. **Browse by section.** Each section below is a folder with a hub note of the same name. Its *In this section* table lists everything inside, so nothing gets lost.
3. **Follow the links, or open the graph.** Every note links up to its hub, and every hub links up to here. The graph shows the whole world, one colour per section.
4. **Big secrets live apart.** Twists and hidden truths have their own notes in **Secrets**, linked to the pages they explain.
5. **Start with the [[World Bible]],** then pick an adventure. The **GM Toolkit** under Meta holds encounters, random tables and session notes.
6. **At the table, use the start screen.** Obsidian opens on a session board with search (it rolls dice too: type `2d6`), the graph, Atlas VTT and a scratchpad.
7. **Adding your own material:** press `Ctrl/Cmd + P` and type **New**: *New Place*, *New Character*, *New Secret* and the rest create a note from the right template in the right folder.
