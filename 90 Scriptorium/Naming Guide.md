# Naming Guide

How place names in [[Kagameru]] are made. Read this before inventing a world, continent, country, city, or village name. Local landmarks follow simpler rules, and personal names are not covered here.

## Roots

Names for the world, continents, countries, kingdoms, and major cities are inspired by real-world words for four concepts:

- **mirror**
- **reflection**
- **time**
- **space**

Draw from many languages, not just one or two. The [[#Root Starter List]] below gives a starting point; any real-world language is welcome.

## Inspired, Never Literal

A name must not be an unmodified dictionary word. Take the root and bend it so it sounds like a real place:

- change the ending
- add a place suffix: *-eth, -arn, -ra, -ia, -or, -mark, -hold, -vik, -abad, -by, -ford*
- shift a vowel
- blend two roots

| Root | Language | Concept | Bent name |
| --- | --- | --- | --- |
| *kagami* | Japanese | mirror | **Kagameru** |
| *amser* | Welsh | time | **Amserra** |
| *Raum* | German | space | **Raumark** |

## It Must Sound Like a Place

- two to four syllables
- pronounceable by an English speaker at the table on first read
- no diacritics, no apostrophes
- no awkward consonant clusters

## Scale Decides How Strict the Rule Is

| Scale | Rule | Example shape |
| --- | --- | --- |
| World and continents | always from the four roots; grand and ancient-sounding | Kagameru |
| Countries and kingdoms | from the four roots, with a country-like ending | Amserra, Raumark |
| Cities | from the roots, shorter, often with a settlement suffix | a bent root + *-by*, *-vik*, *-ford*, *-abad* |
| Villages | a bent root plus a plain suffix, or a common-tongue name | Drychford, Tidwick |
| Forests, inns, roads, landmarks | common-tongue names; leave existing ones as they are | Forest of Thieves, To the Eternal Lady |

## Regional Consistency

Places inside one country or region share a language flavour so the map feels coherent. A traveler should be able to guess roughly where a name comes from.

| Region | Flavour | Basis |
| --- | --- | --- |
| [[Specula]] (continent-wide names) | Latin | the continent's own name |
| [[Lustro]] | Slavic (Polish, Czech, Russian, South Slavic) | Lustro, Ogledal |
| [[Hansha]] | Japanese | Hansha, Utsushi |
| [[Drychwen]] | Welsh and Brythonic | Drychwen |
| [[Scáthan]] | Gaelic (Irish, Scottish) | Scáthan |
| [[Veidra]] | Baltic (Lithuanian, Latvian) | Veidra |
| [[Skuggsjá]] | Old Norse and Scandinavian | Skuggsjá |
| [[Tezcatl]] | Nahuatl and Mesoamerican | Tezcatl |

When a new country or region is defined, add a row here before naming its places.

## Checks Before Adding a Name

- [ ] Not identical or confusingly similar to an existing name in the vault.
- [ ] Not the name of a well-known real place or an existing published setting.
- [ ] Not the name of a real deity, sacred figure, or sacred object, and not obviously built from one (see the [[Style Guide]]).
- [ ] Added to the [[Pronunciation Guide]] with its root language and concept.
- [ ] A short "The Name" section added to its entry.

## Existing Names

These names predate this guide. They stay as they are for now; the table records how each one measures up so a decision can be made later.

| Name | Root | Breaks "inspired, never literal"? | Suggested replacements |
| --- | --- | --- | --- |
| [[Kagameru]] | Japanese *kagami*, mirror | No: bent ending. | — (the model example) |
| [[Specula]] | Latin *specula*, watchtower; *speculum*, mirror | **Yes**: *specula* is an unmodified Latin word. | Specoria, Spekarra |
| [[Drychwen]] | Welsh *drych*, mirror + *gwen*, fair | No: a blend of two roots. Borderline on pronunciation: the Welsh *ch* is unfamiliar to many English speakers. | Drywenna, Drychmor |
| [[Scáthan]] | Irish *scáthán*, mirror | **Yes**: near-literal (one accent dropped), and it still carries a diacritic. | Scathmor, Scathara |
| [[Veidra]] | Lithuanian *veidrodis*, mirror | No: shortened and reshaped. | — (optional: Veidrath) |
| [[Skuggsjá]] | Old Norse *skuggsjá*, mirror | **Yes**: unmodified word, a diacritic, and the cluster *-ggsj-*. | Skuggmark, Skuggara |
| [[Tezcatl]] | Nahuatl *tezcatl*, obsidian mirror | **Yes**: unmodified word, and the final *-tl* is hard for English speakers. The same word is also the root of a real deity's name. | Tezcara, Tezcamor |
| [[Lustro]] | Polish *lustro*, mirror; Latin *lustro*, I purify | **Yes**: unmodified word in two languages. | Lustarn, Lustrovia |
| [[Ogledal]] | Bulgarian, Macedonian, Serbian *ogledalo*, mirror | No: shortened ending. | — (optional: Ogledarn) |
| [[Hansha]] | Japanese *hansha*, reflection | **Yes**: unmodified word. | Hanshara, Hansharu |
| [[Utsushi]] | Japanese *utsushi*, copy or reflection | **Yes**: unmodified word. | Utsushiro, Utsuren |

> [!NOTE]
> The suggestions follow the rules above, but none has been checked against real places or published settings yet. Run the checklist before adopting one. *Lustria* was deliberately avoided because it is an existing published fantasy continent.

The [[Welcome|Library of Kagami]] keeps its name: it is an institution, not a place name, and is named after the same old-tongue root as the world.

## Root Starter List

A starting point, not a limit. Verify spelling and meaning before relying on a root.

| Concept | Roots |
| --- | --- |
| mirror | *kagami* (Japanese), *zerkalo* (Russian), *lustro* (Polish), *speculum* (Latin), *specchio* (Italian), *espejo* (Spanish), *miroir* (French), *Spiegel* (German), *drych* (Welsh), *scáthán* (Irish), *skuggsjá* (Old Norse), *peili* (Finnish), *peegel* (Estonian), *tükör* (Hungarian), *veidrodis* (Lithuanian), *spogulis* (Latvian), *zrcadlo* (Czech), *ogledalo* (South Slavic), *oglindă* (Romanian), *ayna* (Turkish), *kioo* (Swahili), *tezcatl* (Nahuatl), *cermin* (Indonesian) |
| reflection | *hansha* (Japanese), *utsushi* (Japanese), *reflejo* (Spanish), *riflesso* (Italian), *Spiegelung* (German), *heijastus* (Finnish), *odraz* (Czech, Croatian), *adlewyrchiad* (Welsh) |
| time | *amser* (Welsh), *am* (Irish), *Zeit* (German), *tempus* (Latin), *aika* (Finnish), *idő* (Hungarian), *toki* (Japanese), *vremya* (Russian), *czas* (Polish), *zaman* (Turkish, Persian, Arabic), *wakati* (Swahili), *pacha* (Quechua, time and world) |
| space | *Raum* (German), *spatium* (Latin), *gofod* (Welsh), *avaruus* (Finnish), *tér* (Hungarian), *prostor* (Czech), *rymd* (Swedish), *rúm* (Old Norse), *uzay* (Turkish), *espacio* (Spanish), *kūkan* (Japanese) |

Avoid roots that are also the names of gods or personifications, such as *Chronos* or *Kala*.
